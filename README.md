# INFLUENCE.

A premium single-page influencer marketing agency landing page built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Creator photos and metrics are intentionally demo placeholders and should be replaced with approved agency assets and verified figures before launch.

The contact form uses FormSubmit to deliver inquiries to `tarrasuri1999@gmail.com`. The first submission requires confirming the delivery email from FormSubmit.
